2D TETRİS PROJESİ 
Proje Adı 
• 2D Tetris - BGT 132 Final Projesi  

Proje Amacı 
• Bu proje, Yazılım Geliştirme Teknolojileri dersi kapsamında, Nesne Yönelimli 
Programlama (OOP) prensiplerini ve yazılım geliştirme süreçlerini (Gereksinim 
Analizi, UML, Git kullanımı) uygulamalı olarak göstermek amacıyla geliştirilmiştir. 
Temel amaç, klasik Tetris oyun mekaniklerini modüler ve kaliteli bir kod yapısıyla 
sunmaktır.

Özellikler 
• Izgara tabanlı oyun sistemi (35x21) 
• Tetromino parçaları (I, T, L) 
• Akıcı parça hareketleri (sağ, sol) 
• Döndürme sistemi 
• Çarpışma kontrolü (blokları arası etkileşim) 
• Satır temizleme sistemi (en alt satır dolduğunda gerçekleşir) 
• Skor sistemi (ekranın bir köşesinde yazmaktadır) 

Kullanılan Teknolojiler 
• Godot Engine 
• GDScript
